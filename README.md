# 1. Solution Ideation

### UX Problem

Patients find it difficult to book doctor appointments quickly.

### Brainwriting Ideas

1. Search doctors by specialization.
2. Show available time slots.
3. One-click appointment booking.
4. Doctor rating and review feature.
5. Appointment reminder notifications.
6. Online payment option.
7. Easy appointment cancellation.
8. Emergency appointment option.

---

# 2. Creating User Stories

1. As a **patient**, I want to search for doctors, so that I can find the right doctor quickly.

2. As a **patient**, I want to view available time slots, so that I can choose a convenient time.

3. As a **patient**, I want to book an appointment online, so that I can avoid waiting in queues.

4. As a **patient**, I want to receive appointment reminders, so that I do not miss my appointment.

5. As a **patient**, I want to cancel or reschedule appointments, so that I can manage my schedule easily.

---

# 3. Creating Scenarios

### Selected User Story

> As a patient, I want to book an appointment online, so that I can avoid waiting in queues.

### Scenario

Saran needs to consult a doctor but has limited time. He opens the health app at home, searches for a doctor, selects an available time slot, and confirms the appointment. He feels **happy and relieved** because the booking is completed without visiting the hospital.
